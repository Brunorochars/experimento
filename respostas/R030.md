# Revisão de código: `notas.py`

Encontrei **3 defeitos funcionais**.

## Defeito 1: pesos de P2 e T trocados

**(1) Localização:** constante `PESOS`, no início do módulo.

```python
PESOS = {"P1": 0.35, "P2": 0.30, "T": 0.35}
```

**(2) Descrição:** P2 está com peso 30% e T com peso 35%. A RN05 define P2 com 35% e T com 30%.

**(3) Justificativa:** `media()` usa os valores de `PESOS` diretamente. Com P1 = 0, P2 = 10 e T = 0, o código retorna 3,0, mas a RN05 exige 3,5. O erro se propaga para `situacao()` (RN06), `lancar_exame()` (RN07), `media_final()` (RN08) e `ranking()` (RN09). Um aluno pode, por exemplo, ser classificado como "Reprovado" em vez de "Exame", ou ficar fora de ordem no ranking.

**(4) Correção:**
```python
PESOS = {"P1": 0.35, "P2": 0.35, "T": 0.30}
```

## Defeito 2: falta o limite superior da nota (10)

**(1) Localização:** método `_validar_nota`.

```python
if nota < 0:
    raise NotaInvalidaError("nota fora do intervalo")
```

**(2) Descrição:** só o limite inferior é verificado. Notas maiores que 10 (por exemplo, 11 ou 10.5) são aceitas.

**(3) Justificativa:** a RN03 exige nota entre 0 e 10, inclusive, com `NotaInvalidaError` fora desse intervalo. A RN07 diz que a nota de exame segue a mesma validação, então o defeito afeta tanto `lancar_nota` quanto `lancar_exame`. Uma nota inválida pode gerar médias acima de 10 e aprovações indevidas.

**(4) Correção:**
```python
if not 0 <= nota <= 10:
    raise NotaInvalidaError("nota fora do intervalo")
```

## Defeito 3: frequência de exatamente 75% reprova

**(1) Localização:** método `situacao`, segunda verificação.

```python
if aluno.frequencia <= FREQUENCIA_MINIMA:
    return "Reprovado por frequência"
```

**(2) Descrição:** o operador `<=` reprova por frequência um aluno com exatamente 75%.

**(3) Justificativa:** a RN06, item 2, diz que só reprova por frequência quem tem frequência *menor* que 75% e acrescenta que "75% exatos não reprovam por frequência". Hoje um aluno com 75% e média 9,0 recebe "Reprovado por frequência" em vez de "Aprovado". Também fica impedido de fazer exame (RN07), pois a situação nunca será "Exame".

**(4) Correção:**
```python
if aluno.frequencia < FREQUENCIA_MINIMA:
    return "Reprovado por frequência"
```
