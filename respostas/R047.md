# Revisão de código: `notas.py`

Encontrei **3 defeitos funcionais**.

---

### Defeito 1: Pesos de P2 e T trocados

**(1) Localização:** constante `PESOS`, no topo do módulo.
```python
PESOS = {"P1": 0.35, "P2": 0.30, "T": 0.35}
```

**(2) Descrição:** P2 tem peso 0,30 e T tem peso 0,35. O requisito define o contrário.

**(3) Justificativa:** RN05 define P1 = 35%, **P2 = 35%** e **T = 30%**. Com os pesos atuais, `media()` produz valores errados sempre que P2 ≠ T. Exemplo: P1 = 0, P2 = 10, T = 0.
- Esperado: 3,5.
- Obtido: 3,0.

O erro se propaga para `situacao()`, `media_final()`, `lancar_exame()` e `ranking()`.

**(4) Correção:**
```python
PESOS = {"P1": 0.35, "P2": 0.35, "T": 0.30}
```

---

### Defeito 2: Falta o limite superior na validação da nota

**(1) Localização:** método `_validar_nota`.
```python
if nota < 0:
    raise NotaInvalidaError("nota fora do intervalo")
```

**(2) Descrição:** só o limite inferior é verificado. Notas acima de 10 (por exemplo, 11 ou `float('inf')`) são aceitas. Valores `NaN` também passam, porque `NaN < 0` é falso.

**(3) Justificativa:** RN03 exige nota entre 0 e 10, inclusive, e `NotaInvalidaError` fora desse intervalo. RN07 aplica a mesma validação à nota de exame. Assim, tanto `lancar_nota` quanto `lancar_exame` aceitam valores inválidos. Isso pode gerar médias acima de 10 ou aprovações indevidas.

**(4) Correção:**
```python
if not 0 <= nota <= 10:
    raise NotaInvalidaError("nota fora do intervalo")
```
Essa forma também rejeita `NaN`, porque qualquer comparação com `NaN` é falsa.

---

### Defeito 3: Frequência de exatamente 75% reprova por frequência

**(1) Localização:** método `situacao`, segunda verificação.
```python
if aluno.frequencia <= FREQUENCIA_MINIMA:
    return "Reprovado por frequência"
```

**(2) Descrição:** o operador `<=` reprova também quem tem exatamente 75%.

**(3) Justificativa:** RN06, item 2, diz que só frequência **menor que** 75% reprova, e ressalta que "75% exatos não reprovam por frequência". Hoje, um aluno com 75% de frequência e média 9,0 recebe `"Reprovado por frequência"` em vez de `"Aprovado"`. Isso também impede `lancar_exame` para alunos com 75% e média entre 5,0 e 7,0.

**(4) Correção:**
```python
if aluno.frequencia < FREQUENCIA_MINIMA:
    return "Reprovado por frequência"
```
